# Changelog

## 0.1.0

- Monopoly-style property-trading game for 2–6 players on a Drawdy board.
- Four themes: Classic City, Thailand, Space Frontier and Fantasy Realm, all sharing the same economy.
- Official US rules with configurable house rules (starting cash, salary, free parking jackpot, auctions, even building, jail rent, jail fine, round limit, building supply).
- Cloud-board multiplayer with automatic host handover when the host leaves.
- Hot-seat play with several local players on one device.
- Buy, auction, build, sell, mortgage, trade, jail options, debt and bankruptcy.
- Control panel with a game list, new-game form, lobby, in-game tabs (Assets, Players, Trade, Log, Rules).
- Board, tokens, dice, houses and scoreboard drawn on the canvas.
- Name tags above every token that hop along with it (initials only when a tile is crowded).
